##  Project Overview

The **Local Vendor Credit Management System** is a Java-based command-line application developed as part of the **BYOP (Bring Your Own Project)** initiative.  

This project is inspired by a real-world problem commonly seen in local shops and small businesses, where vendors maintain credit (udhar) records manually in notebooks. These manual records are often unorganized, error-prone, and difficult to manage.

This application provides a **simple, digital solution** to manage customer credit transactions efficiently, accurately, and permanently using file handling.

---

##  Problem Statement

Small vendors often face difficulties in managing credit transactions due to:
- Manual record-keeping errors  
- Difficulty in tracking multiple customers  
- Risk of losing physical records  
- Time-consuming calculations  

 This project solves these problems by creating a **structured and automated system** for managing credit records.

---

##  Objectives

- Replace manual record-keeping with a digital system  
- Maintain accurate customer transaction records  
- Automatically calculate balances  
- Ensure data persistence using file handling  
- Provide a simple and easy-to-use interface  

---

##  Features

-  Add new customers  
- Record credit (given) and debit (received) transactions  
-  Automatic balance calculation  
-  View complete transaction history  
-  Data stored permanently using file handling  
-  Simple menu-driven interface (beginner-friendly)

##  How the System Works

- You can add customers and record their transactions  
- Transactions are of two types:
  - **Credit** → Customer owes money  
  - **Debit** → Customer pays money  
- The system automatically updates the balance  
- All data is saved in `data.txt`  
- When you restart the program, data is loaded again  

---

##  File Handling (Important Feature)

This project uses file handling to:
- Save all customer and transaction data  
- Load data automatically when program starts  

 This ensures that **no data is lost**, making the system practical and real-world usable.
